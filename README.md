# OLD RACING

An original Android highway-racing prototype built with Kotlin and a custom Canvas renderer.

- Four-lane divided highway: two lanes in each direction.
- One-way and two-way modes.
- Three starter cars inspired by Mustang GT, BMW M4 and Opel Astra GTC (stylized placeholders, not licensed 3D models).
- Touch steering, speed controls, traffic, distance, collision and restart.
- GitHub Actions builds a debug APK artifact automatically.

This first version is a pseudo-3D prototype, not a full 3D game. Realistic branded models require appropriately licensed assets.
